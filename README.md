# しゅーとアーク（shot-arc）

iPadのSafariで、1人で打つシュートの軌道を測るWebアプリ。打つたびに「にゅうしゃかく」と「リングのどこを通ったか（てまえ／まんなか／おく）」を声と画面で知らせ、1本ごとの数字と短い動画をiPadの中に保存します。映像とデータはiPadの外に出ません（書き出したときだけ）。

## はじめに（1回だけ）
1. iPadのSafariで `probe.html` を開き、共有ボタン →「ホーム画面に追加」。ホーム画面から開いて「はじめる」。結果を「コピー」して送る（このiPadでどこまで使えるかを測ります）
2. `index.html` も同じように「ホーム画面に追加」する（データが消えにくくなります）

## おきかた
- 三脚で、ゴールの **真横** に置く（シュートの向きと直角）
- リング全体と、うつ人・ボールの軌道が画面に入る高さと距離にする
- 横向きで使う。うつ人が画面の左右どちらにいるかを、位置合わせの画面でえらぶ

## つかいかた
1. うつ人をえらぶ
2. 位置合わせ：みどりの枠がリングに合っていれば「OK」。ずれていたら、リングの左はし・右はしをタップ
3. うつ。1本ごとに声と数字が出る
4. 「おわり」でその回のまとめ

## きろく・かきだし
- ホームの「きろく」から、日付→回→1本ずつ見られる。▶で動画（0.25倍・0.5倍・コマおくり）
- 結果（はいった／はずれ）はタップで直せる（直したものに＊）
- 「すうじを かきだす（CSV）」→ 共有メニューからPCへ（Excelで開けます）
- 動画は1本ずつ／回ごと／「かきだしずみの どうがを ぜんぶけす」で消せる。数字は残る
- かきだしていない記録が100本、または7日分たまると、ホームに知らせが出る

## 開発
- 設計：`docs/design.md`、実装計画：`docs/plan.md`
- テスト：`npm install` のあと `npm test`
- PCで練習動画にかける：`node tools/bench.mjs <動画> --rim 左はし,右はし,高さ --side right`（元動画の画素）。ブラウザなら `analyze.html`
